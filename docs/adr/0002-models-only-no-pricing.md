# ADR 0002: 数据来源与展示范围——只要模型，不要价格

- 状态: 已接受
- 日期: 2026-09-24

## 背景

提供商有两种取数接口：

- 中转站 `/api/pricing`：返回模型 + 价格。
- `/v1/models`（+ key）：只返回模型列表。

需要决定 ModelHub 到底展示什么。

## 决策

**只展示"可用模型列表"，不展示价格。**

- 抓取逻辑：能拿到模型列表即可，无论走 `/api/pricing` 还是 `/v1/models`。
- 价格字段即使 `/api/pricing` 返回了，也忽略不展示、不存储。
- Provider 详情页 = 该提供商的可用模型清单。

## 影响

- 数据模型简化为 Provider -> [Model名/ID]，无价格字段。
- 抓取器需要归一化两种接口返回的模型列表到统一结构。
- 后续若要加价格，是增量改动（`/api/pricing` 本就带价格），不阻塞当前设计。
