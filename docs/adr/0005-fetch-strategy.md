# ADR 0005: 模型抓取策略——定时 + 手动 + 缓存

- 状态: 已接受
- 日期: 2026-09-24

## 背景

需确定何时抓取上游模型列表，以及抓取失败时的展示行为
（ADR-0002 只抓模型、ADR-0003 模型缓存进 JSON）。

## 决策

### 抓取时机

- **定时自动刷新**：每 6 小时刷新一次全部提供商的模型列表（间隔可配置）。
- **手动刷新**：详情页/卡片提供"刷新"按钮，立即重抓单个提供商。
- 添加/编辑提供商时立即抓一次（首次填充缓存）。
- 前端读取始终来自缓存（`models` 字段），不在渲染时实时打上游。

### 失败行为

- 抓取失败**保留上次成功缓存的模型**，不清空。
- 每个提供商记录抓取状态：`last_fetched`、`last_status`（ok/error）、`last_error`。
- 卡片显示状态徽章（正常 / 上次刷新失败）；详情页显示错误详情。

## 影响

- 需要一个定时调度器（后端进程内 setInterval / 轻量 cron）。
- Provider 数据结构补充字段：`last_fetched`、`last_status`、`last_error`。
- 刷新间隔存为配置项（默认 6h）。
- 定时任务需容错：单个提供商失败不影响其他。
