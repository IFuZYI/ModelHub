# ADR 0001: 范围——单用户私有控制台

- 状态: 已接受
- 日期: 2026-09-24

## 背景

ModelHub 用于聚合查看多个 API 提供商（Provider）的可用模型与价格。
提供商分两类：

- 官方（OpenAI、Anthropic、Google 等）
- 中转站（newapi 类，支持 `/api/pricing`、`/v1/models`）

需要先确定使用范围，因为它决定了认证、存储、后端的整体形态。

## 决策

ModelHub 是一个**单用户私有工具**：

- 只有一个控制台（Console），只有拥有者（你）使用。
- 只有拥有者能添加/设置提供商。
- 无公开访客、无多用户注册、无 key 分享给他人。

## 影响

- 不需要用户系统、注册、权限分级。
- 后端可以安全存储各提供商的 API key（因为只服务于拥有者本人）。
- 仍需对控制台本身做最低限度访问保护（见后续 ADR：本地绑定 / 单一口令）。
- 简化为：一套配置 + 一个后端代理 + 一个前端界面。
